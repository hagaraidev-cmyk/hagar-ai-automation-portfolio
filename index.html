PROJECT 01

AI-Powered Order Management

Problem: Managing product inquiries, checking stock availability, recording customer orders, and updating inventory manually can be time-consuming and may lead to errors or inconsistent records..

Solution: Developed an AI-powered e-commerce chatbot workflow using n8n and specialized AI agents. It checks product information and availability in Google Sheets, suggests available alternatives, collects order details after customer confirmation, records confirmed orders, and updates inventory following successful order creation. Technologies

PROJECT 02

RAG Knowledge Assistant

Problem: Financial reports contain large amounts of information, making it time-consuming to find specific figures, compare quarterly results, and extract relevant insights manually.

Solution: Built an AI-powered RAG chatbot using n8n that retrieves relevant information from Apple's quarterly financial reports stored in Pinecone. It uses OpenAI embeddings and GPT-4.1 mini to answer questions with concise, report-based insights, identify the relevant quarter, and acknowledge when the available data is insufficient. Technologies

RAG Google Drive Google Sheets Pinecone OpenAI n8n
n8n + AI Agent + Google Integrations
PROJECT 04

AI Personal Assistant

Problem: Managing daily tasks, emails, calendar events, image analysis, and social media content across multiple tools can be time-consuming and repetitive.

Solution: An AI-powered personal assistant built with n8n that receives text, voice messages, and images, understands user requests, and executes tasks through integrated services. It supports voice responses to voice messages, analyzes images, manages Google Calendar events, sends and receives emails through Gmail, generates social media posts and stores them in Google Sheets, and performs web searches using SerpAPI when requested.

n8n AI Agents Voice & Image Processing Google Calendar Gmail Google Sheets SerpAPI API Integration

Future enhancement: Enable automated publishing of generated social media posts directly to supported platforms.
